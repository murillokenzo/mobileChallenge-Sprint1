# Nexo Nuclear

## Sobre o projeto

O Nexo Nuclear é um aplicativo educacional desenvolvido em Flutter com o objetivo de apresentar informações sobre o Programa Nuclear da Marinha do Brasil, explicando sua importância, aplicações e contribuições para o desenvolvimento científico e tecnológico do país.

A solução busca tornar o conhecimento sobre tecnologia nuclear mais acessível e interativo por meio de conteúdos educativos, recursos visuais e atividades de aprendizagem.

## Funcionalidades

- **Introdução:** apresentação do Programa Nuclear da Marinha e seus principais objetivos.
- **Mapa Interativo:** exploração de informações e locais relacionados ao programa.
- **Quiz:** questionário interativo para testar e reforçar os conhecimentos adquiridos.

## Como executar o projeto

1. Instale o Flutter SDK.
2. Instale o Visual Studio Code.
3. Configure o Flutter e o Dart no ambiente de desenvolvimento.
4. Clone este repositório:

```bash
git clone https://github.com/murillokenzo/mobileChallenge-Sprint1.git
```

5. Entre na pasta do projeto.
6. Instale as dependências:

```bash
flutter pub get
```

7. Execute o aplicativo:

```bash
flutter run
```
